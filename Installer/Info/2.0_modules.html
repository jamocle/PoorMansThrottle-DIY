PMT 2.0

Modules have arrived.

Version 2.0 expands PMT beyond train throttles and introduces a new module ecosystem. The first released module is PoorMansTurbine, and the new module foundation opens the door for future plugins such as railroad switch control, layout lighting, layout sound, and other specialized accessories.

A new module platform for the PMT ecosystem

PMT 2.0 adds module-style device support so the app can discover module devices, show them separately from locomotive throttles, and open the correct module-specific control and configuration experience. The goal is simple: create a growing PMT ecosystem where dedicated devices can be built for different layout and maintenance jobs.

What modules enable

PMT can now grow beyond throttles

Modules make it possible for PMT to support specialized devices that are not train throttles. That means the platform can continue expanding into other railroad and layout roles while still using the same familiar PMT app and shared device family.

Future plugin ideas

The ecosystem is expanding

Future module plugins can be created for railroad switches, layout lights, layout sounds, maintenance tools, and other purpose-built layout accessories. The module system is intended to make those additions feel like part of one connected PMT platform.

PMT 2.0 is the first release where throttle, module, and turbine devices all share the same 2.0 firmware generation and app support.

PoorMansTurbine: the first PMT module

PoorMansTurbine is designed for high-speed brushless fans driven by an Electronic Speed Controller (ESC), such as a Flycolor 50A ESC 2–4S electric speed controller, though other ESCs can be used as well. It is well suited for accessories like snow blowers, track blowers, smoke systems, and similar high-airflow applications.

Purpose

Built for high-speed fan control

PoorMansTurbine provides ESC-style output control for fan-driven accessories where fast airflow is the goal. That makes it a strong fit for track-clearing and snow-clearing tools, as well as other experimental layout accessories that benefit from controlled fan output.

Dedicated app experience

Module-aware control and configuration

PMT 2.0 adds a dedicated turbine control screen with a turbine output dial, stop control, live output readback, and a saved governor limit. The app also adds guided ESC calibration plus turbine configuration for minimum output, full output, ramp time, ESC PWM pin, and dial tap behavior.

On the firmware side, the 2.0 release adds PoorMansTurbine firmware, ESC-style output commands, turbine output tuning, low-voltage protection support, scheduled command execution, and the shared module foundation used across the PMT 2.0 family.

App 2.0 highlights

The PMT app now understands both throttle devices and module-class devices, including PoorMansTurbine.

  • App support for PoorMansTurbine discovery, connection, configuration, and control.
  • A dedicated turbine control screen with live output, stop control, and governor limit support.
  • Guided ESC calibration with safety prompts and automatic restoration of previous output limits.
  • Turbine configuration support for minimum output, full output, ramp-to-full time, ESC PWM pin, and dial behavior.
  • Module-style device support on the scan screen so modules are recognized separately from train throttles.
  • Minimum supported firmware updated to 2.0.0 across the shared PMT device family.
  • Improved WebSocket backup connection behavior and known-device scanning.
  • Expanded localization, accessibility, diagnostics, and version-information experiences.

Firmware 2.0 highlights

Firmware 2.0 establishes the shared module and turbine generation that the new app release is built around.

  • Shared firmware versioning now spans Throttle, Module, and Turbine firmware in the 2.0 family.
  • PoorMansTurbine firmware added for ESC-style output control of turbine, smoke, fan, and similar accessory modules.
  • Turbine output commands and tuning added for normal output, immediate changes, output queries, and quick-blast behavior.
  • Battery-protection behavior added for low-voltage shutdown and output limiting when configured.
  • PoorMansModule shared firmware foundation added with common BLE, Wi-Fi, WebSocket, identity, debug, schedule, naming, reset, and telemetry capabilities.
  • Scheduled command execution expanded across supported firmware images, including module and turbine devices.
  • Manual time support and backup WebSocket handshake support added.
  • BLE command processing and battery telemetry delivery reliability improved.
