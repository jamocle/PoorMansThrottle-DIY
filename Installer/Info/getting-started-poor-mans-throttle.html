The PMT Recipe

A simple way to think about a Poor Man’s Throttle build is to start with the basic recipe, then add only the extra ingredients your project needs.

PMT Recipe
Build in layers.
Start with the core throttle hardware, then add sound and battery management only if your installation needs them.

Basic Recipe

This is the foundation for a working PMT throttle installation.

1
ESP32Use either a Classic ESP32 or an ESP32-S3.
2
Motor DriverChoose the driver that matches your locomotive’s voltage, current, and available space.
3
Buck ConverterSteps common track or battery voltage down to the regulated power your controller needs.
+
Automation needs an SD readerIf you want automation capabilities, add an SD-card reader unless you are using a board that already includes one.

Sound Add-on

Add this on top of the Basic Recipe when you want PMT audio features.

S
Highly recommended: ESP32-S3The S3 is the preferred choice when adding sound capabilities.
1
AmplifierUse one of the optional sound-card / amplifier modules shown below.
2
SpeakerPair the amplifier with a suitable speaker for your installation.
3
SD-card readerRequired if you are not using the CAM board, which already includes one.

Battery Management Add-on

Add this when you want PMT to monitor battery conditions and help prevent undervoltage issues.

B
INA219Add the INA219 module for battery monitoring and management support.

Optional hardware

Add only what your installation needs

These modules are useful for specific PMT features but are not required for every basic throttle installation.

OPTIONAL Sound cards

Use these only when your installation includes PMT audio features.
For basic throttle control without audio, these sound-card modules are not required.

Alternative motor drivers

Match the driver to the locomotive
