Important Setup Guidance

Stop and read this before using Poor Man's Throttle.

Minimum Start Throttle and Maximum Throttle help match the throttle response to the way a locomotive actually moves, so acceleration feels smoother, more predictable, and easier to control.

This is important. These are not minor settings. If they are set poorly, the locomotive can hesitate at low throttle, jump into motion later than expected, or waste part of the throttle range where no real speed change happens. A few minutes spent understanding this will make operation much smoother.

Why these settings matter

Not every motor starts moving the instant the throttle leaves zero. On many locomotives, the first few low throttle values do not create enough power to make the motor turn. That can cause a delay where the user raises the throttle but the locomotive still does not move.

Minimum Start Throttle fixes that by setting the lowest useful starting point. Instead of wasting the first part of the throttle range on values that do nothing, the app can begin at the point where the motor actually starts responding. That makes low-speed control feel more immediate and much smoother.

Minimum Start Throttle Think of this like pushing a bicycle just hard enough to get it rolling. Too little force does nothing. This setting finds the point where the motor begins to move, so the locomotive does not hesitate when the throttle is first raised.
Why it matters This is especially important for smooth locomotive operation. It helps remove dead space at the bottom of the throttle range, reduces delayed starts, and makes slow movement feel more controlled and realistic.
Cutting off the top-end dead zone Many motors reach a point where increasing the throttle no longer makes them go any faster. If that happens, Maximum Throttle can be set at that useful top point so the extra, non-helpful range is removed.
Maximum Throttle (Governor) This is the ceiling. Like a car governor. It sets the highest output the locomotive will use at 100%. You can use it as a speed limiter to keep a locomotive from running faster than you want.

In simple terms, Minimum Start Throttle helps the locomotive start moving sooner, and Maximum Throttle helps the locomotive stop accelerating at the right point. Together, they shape the throttle range so more of it is useful.

That means less time spent in low-throttle values where nothing happens, and less time spent at high-throttle values where the motor is already at full practical speed. The result is a throttle that feels more responsive, smoother, and easier to understand.

Do not skim past this. These settings have a major effect on how the locomotive behaves. Getting them right can make the difference between jerky, frustrating control and smooth, predictable operation.
A good way to think about it: Minimum Start Throttle removes the dead zone at the bottom, and Maximum Throttle removes the dead zone at the top. Together, they help the locomotive use the throttle range more effectively.

The idea is simple: match the controls to the real behavior of the motor. When the settings line up with how the locomotive actually starts and tops out, operation becomes smoother and more consistent.
