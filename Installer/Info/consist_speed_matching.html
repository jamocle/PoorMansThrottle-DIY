MU Consisting Upgrade

Real-time speed matching for every locomotive in the consist.

The newest MU Consisting feature lets you build a custom power curve for each locomotive, so mixed models can accelerate, decelerate, stop, and brake together instead of fighting one another.

The old problem: a tug-of-war inside the consist

Different locomotive models use different motors, gear ratios, and power curves. Two engines can receive the same throttle command and still move at very different speeds. When those locomotives are coupled together, the faster one pushes while the slower one drags, creating uneven tractive effort and unnecessary strain.

Before

Same throttle, different result

A throttle value of 20 might barely move one locomotive while another is already running too fast.

Now

Each locomotive gets its own profile

A per-consist speed curve changes the output sent to each locomotive so every engine contributes more evenly.

The goal is steady tractive effort: every locomotive pulls its share instead of pushing or dragging against the others.

How real-time speed matching works

The matching screen shows a master throttle and a separate response curve for each locomotive in the consist. As the master throttle moves, a line on each graph shows the current point in the power band and the output that will be sent to that locomotive.

Each circular point on the graph represents an adjustable speed point. Move a point down to slow a locomotive at that part of the throttle range, or move it up to increase its output. Adjust the faster locomotive, the slower locomotive, or both until they travel together.

The best way to compare one locomotive to another is to look at the two locomotive cards side by side at the same master throttle setting. In the example above, each card shows how that locomotive maps the same master input to its own output, making it easy to spot which locomotive needs to be sped up or slowed down.

The curve is attached to the consist, so the same locomotive can use a different profile when it is part of another consist.

Live switch

Preview or control in real time

When Live is ON, the master throttle sends real-time commands to the locomotives and the displayed outputs are applied immediately. When Live is OFF, the screen is only a preview of the graph and no commands are sent to the locomotives.

Separate curves by consist direction

Use one curve or two

This switch enables a second power curve for the locomotive. With it off, the same curve is used in both directions. With it on, you can create one curve for consist-forward operation and another for consist-reverse operation, which is useful when a motor performs differently in forward and reverse.

Reset

Return to a standard linear curve

The Reset button restores the selected power curve to the default straight-line graph. This removes all custom power adjustments for that curve and returns output to a standard one-to-one response.

Recommended matching procedure

The most accurate results come from observing the locomotives together on the same track while they are uncoupled.

1

Place them on the track

Put all locomotives on the same track, uncoupled, so their movement is easy to compare.

2

Start with two

Match the first two engines before adding the next locomotive, then repeat.

3

Enable Live mode

Turn on Live when you are ready for the matching screen to send commands to the locomotives.

4

Begin slowly

Move the master throttle up from zero and watch how the locomotives behave relative to one another.

5

Adjust the graph

Lower points for a locomotive that is too fast or raise them for one that is too slow.

6

Work through the range

Repeat at several speeds so the locomotives remain matched from startup through higher-speed operation.

Customize the momentum of the entire consist

Speed matching controls how each locomotive responds relative to the master throttle. Momentum settings control how quickly the whole consist changes speed.

Enable momentum

Turn consist momentum on or off

The Enable Momentum switch controls whether momentum behavior is active for the consist. When it is off, the consist responds without the configured ramp timing. When it is on, the Drive, Stop, and Brake times below are used.

Drive ramp

Control acceleration

Set how long the consist takes to ramp toward a new drive command.

Stop ramp

Control normal stopping

Adjust how quickly the consist ramps down when a standard stop command is used.

Brake ramp

Control braking behavior

Define a separate braking time so brake commands can feel different from an ordinary stop.

Per-consist control

Different trains, different behavior

Each consist can be tuned for its own locomotive mix, train weight, and operating style.

The result is fully customizable control over your consist: matched locomotive output, smoother acceleration, controlled braking, and more even pulling power across every engine.
