Poor Man's Throttle 3.2

Firmware updates without the USB cable.

Supported ESP32-S3 PMT devices can now update wirelessly, directly from the app. PMT checks compatibility, guides the update, protects the controls, waits for the restart, verifies the new firmware, and refreshes the device automatically.

A guided update from start to finish.

OTA in PMT 3.2 is more than a wireless flash button. The app manages the entire experience: capability detection, Wi-Fi readiness, confirmation, update protection, reboot handling, firmware verification, and configuration recovery.

Automatic compatibility check

The app asks the connected device whether OTA is supported instead of guessing from its name or firmware version.

Built into Configuration

Compatible hardware receives a Flash Firmware option directly in the device Configuration screen.

Wi-Fi guidance

If the device supports OTA but Wi-Fi is unavailable, the app explains what is needed before the update can begin.

Protected update state

Once flashing starts, controls are temporarily locked so the update cannot be interrupted by normal device commands.

Automatic restart handling

The app expects the PMT Device to disconnect and reboot, then waits for it to become available again.

Verified before returning control

After reconnecting, the app authenticates again, reads the running firmware version, and refreshes the device configuration.

Need the exact firmware build?

For manual diagnostics, send VV from the PMT terminal. Firmware 3.3.0 revision 248 returns ACK:V3.3.0.248. The existing V command still returns the semantic version only, for example ACK:V3.3.0.

GREEN Update activity
PURPLE Alternating during OTA
Do not remove power during an update. The PMT Device restarts automatically when installation is complete. The GREEN/PURPLE onboard RGB indication during OTA is expected behavior and alternates every 300 ms while OTA is active.

What the customer experiences.

The process is intentionally simple. The technical work happens behind the scenes while the app keeps the user informed.

1
Connect

Connect to the PMT Device normally and open Configuration.

2
Update

Select Flash Firmware. The app verifies OTA readiness and asks for confirmation.

3
Wait

The interface switches to a dedicated update state and prevents conflicting controls.

4
Automatic restart

The PMT Device installs the latest compatible firmware and reboots by itself.

5
Automatic verification

The app reconnects, authenticates, and confirms the firmware version actually running on the device.

6
Ready to use

The device configuration is refreshed and controls are restored only after synchronization is complete.

What the progress percentage means.

Firmware transfer progress is reported in 10% steps. Preparation happens before the first percentage is shown.

Before 0%

The device may be stopping safely, confirming Wi-Fi, obtaining private OTA validation time, or reading and validating the firmware catalog.

0%

The actual firmware image transfer/write phase has started.

10% through 90%

The app receives firmware transfer/write progress in exact 10% buckets.

100%

The firmware image transfer/write completed successfully. The device will disconnect and reboot next; no separate final success message is required.

If the update fails: ERR:NO WIFI means Wi-Fi was unavailable or was lost. ERR:OTA means another OTA step failed. If OTA cannot be completed, use the normal USB installer as the recovery path.

Hardware support.

OTA is capability-based. The app asks the device directly whether wireless updating is available.

ESP32-S3 PMT hardware

Supported S3 hardware can update over the air when connected to Wi-Fi. The S3 N16R8 and N8R8 variants use the same OTA experience in the app. OTA always targets the current catalog latest firmware for the detected S3 target. If that catalog version is older than the firmware currently running, CV15=0 (the default) rejects the downgrade and CV15=1 explicitly permits it.

Classic ESP32 PMT hardware

Classic ESP32 hardware continues to use the existing USB firmware-update process. The app will not present OTA as available when the device reports that it is unsupported. USB also remains the recovery and specific-version/rollback path for S3 hardware; CV15=1 only permits an older catalog latest and does not select a historical version.
