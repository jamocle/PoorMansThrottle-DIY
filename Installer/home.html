What is PMT? Poor Man’s Throttle is a completely FREE DIY wireless train control system that lets you run DC and dead-rail (Battery) locomotives from your phone using inexpensive ESP32-based hardware. Build it yourself, tune it yourself, and keep your railroad open, affordable, and fun.

Use this page to install the latest firmware, download the mobile app, open documentation, watch build videos, and get help from Wigand, the PMT AI assistant.

FAQ (Frequently Asked Questions)
What are the basic parts required for an installation of PMT including sound?

A basic PMT installation with sound has three main parts for controlling the locomotive, plus the audio hardware:

  • ESP32 controller — the brains of PMT.
  • 5V power converter — supplies the ESP32 with the power it needs.
  • Motor driver — controls power to the locomotive motor.
  • I2S audio amplifier — such as a MAX98357A, to produce the sound.
  • Speaker — connected to the audio amplifier.
  • microSD card — stores the locomotive sound files.

Some ESP32 boards also require a separate microSD card reader. The ESP32-S3-CAM version has a built-in microSD slot, so it does not need the separate reader.

More information: Full Hardware Recipe · PMTPlayer Audio Installation Guide

I don't need sound. What are the basic parts required for an installation of PMT without sound?

If you do not want sound, a basic PMT installation only needs three main electronic components:

  • ESP32 controller — the brains of PMT.
  • 5V power converter — provides the correct power for the ESP32.
  • Motor driver — controls the locomotive motor. Choose one that is suitable for the motor and current requirements of your installation.

Your locomotive's motor and battery or other power source connect to these components, but they are not additional PMT electronics.

You do not need the audio amplifier, speaker, or microSD card used for a sound installation. Sound can always be added later.

More information: Full Hardware Recipe · PMT Installation Options

I don't want to use a mobile device as a throttle. How can I use a physical throttle instead?

PMT supports physical Bluetooth throttles. You can use a compatible Bluetooth HID device—such as a game controller, button pad, macro pad, or a custom throttle with real buttons, knobs, and switches.

Pair the physical controller, then use PMT's Physical Controls screen to assign its buttons and controls to the functions you want. Once configured, you can operate with the physical controls instead of using the touchscreen as your throttle.

The PMT app is still part of the connection: it receives the physical controller's input and sends the appropriate commands to the locomotive. The physical controller does not connect directly to the locomotive by itself.

You can start with an off-the-shelf Bluetooth HID controller or build your own custom throttle.

More information: Let's Get Physical — PMT Physical Controls · Output Control Guide

How do I tell if my IBT-2 Motor Driver is good or bad?

You can bench-test the IBT-2 with a 12V power source, a separate 5V logic source, and a small DC motor.

With the board powered correctly and both enable pins turned on, test one direction at a time:

  • RPWM HIGH / LPWM LOW — the motor should turn one direction.
  • RPWM LOW / LPWM HIGH — the motor should turn the opposite direction.

The results are simple:

  • Motor runs both directions: the IBT-2 is good.
  • Motor runs in only one direction: one side of the IBT-2 is bad.
  • Motor runs in neither direction: check the wiring and power before assuming the board is bad.

Before condemning the board, make sure VCC is 5V, the grounds are connected together, R_EN and L_EN are HIGH, and the motor and power supply are known to be good.

Important: Do not put 12V into the IBT-2's VCC logic pin.

More information: IBT-2 Quick Test · IBT-2 Test Video

I just want to use PMT to power my old train set with no locomotive modifications. How can I do that?

If you have a traditional DC track-powered train set, you can install PMT completely outside the locomotive.

Place the PMT controller between your transformer and the track:

Transformer → PMT Controller → Track → Locomotive

The transformer supplies the power, while PMT controls the power going to the rails. Your locomotive remains unchanged and simply picks up its power from the track as it always has.

A small project box can hold the PMT electronics, such as the ESP32, motor driver, fuse, and wiring terminals. This makes the system easy to install or remove without modifying your trains.

One thing to remember: PMT controls the powered section of track, so any locomotive on that same powered section receives the same track power.

More information: PMT Power Configuration Guide · Installation Options — Trackside DC Controller Box

Can I use Track Power to power PMT? What does that look like?

Yes. PMT can be installed inside the locomotive and powered from the track.

In this setup, the track is kept at a constant voltage from your transformer. The locomotive's existing track pickups bring that power into PMT.

Track Power → Locomotive Pickups → PMT Electronics → Motor

PMT then controls the locomotive's motor instead of varying the voltage on the track. A 5V power module is used to provide the correct power for the ESP32, while the motor driver controls the locomotive motor.

Because the track stays powered, it can also continue supplying power to things such as lights, buildings, and other accessories.

If each locomotive has its own PMT controller, multiple PMT-equipped locomotives can be controlled independently while sharing the same powered track.

More information: PMT Power Configuration Guide · PMT Build Guide · Wiring Reference

How do I install Dead Rail/Battery powered PMT?

With a Dead Rail installation, the locomotive carries its own battery and does not depend on the rails for power.

A basic installation looks like this:

Battery → Fuse → Motor Driver → Locomotive Motor

The same battery also feeds a 5V power module, which supplies the correct power to the ESP32:

Battery → 5V Power Module → ESP32

If the battery voltage is too high for your locomotive motor, an optional buck converter can be placed before the motor driver to reduce the voltage.

The battery and PMT electronics can be installed inside the locomotive, in a tender, or in a battery car, depending on how much space you have.

With true Dead Rail operation, the rails do not need to be powered. Each PMT-equipped locomotive carries its own power source and can be controlled independently.

More information: PMT Power Configuration Guide · Installation Options · PMT Build Guide

What SD card size should I use and how should I format it for use with PMT?

PMT does not require a large microSD card. A small card is fine — even 128 MB is enough for a typical PMT sound installation.

The important part is formatting the card correctly:

  • 128 MB through 2 GB: format as FAT16.
  • 4 GB through 128 GB: format as FAT32.
  • Do not use exFAT.

Be especially careful with 64 GB and 128 GB cards. They are often sold already formatted as exFAT, so they must be reformatted to FAT32 before PMT can use them.

If you are buying a card specifically for PMT, there is generally no need to buy a very large one.

More information: PMTPlayer Audio Installation Guide

How do I control LED lights?

PMT can control LED lights directly from the ESP32 using its Output Controls.

For each light, you configure:

  • Name — such as Headlight, Reverse Light, or Ditch Light.
  • Pattern — for example Solid, Blink, Ditch Light, Strobe, or other lighting effects.
  • GPIO Pin — the ESP32 output pin connected to that light.
  • Direction — Both, Forward, or Reverse.

For example, a headlight can be configured as LED Solid / Forward, while a rear light can be LED Solid / Reverse. PMT will then only operate each light in the appropriate direction.

PMT supports up to 12 firmware FX outputs, so you can configure several independent lights and effects.

LEDs connected directly to an ESP32 GPIO must use an appropriate series resistor, because the GPIO output is 3.3V. Each independently controlled LED output should also use its own GPIO pin.

More information: Lighting and Auxiliary Outputs · Output Control User Guide · Wiring Reference

Firmware Installation

Step 1

Which ESP32 board family do you have?

Choose Classic ESP32-WROOM-32 or ESP32-S3. If you choose ESP32-S3, the installer will ask whether the metal module is marked N16R8 or N8R8 before any firmware install controls are shown.

Not sure? Do not guess. Compare the board in your hand with the pictures before continuing.

Step 1A

Which ESP32-S3 module do you have?

Check the writing on the metal ESP32 module itself. Find N16R8 or N8R8 in the printed module designation. These modules use different flash sizes and different firmware.

If you cannot tell which version you have, try N16R8 first. If the firmware flashes but the throttle does not start normally, connect to, or work correctly with the Poor Man’s Throttle app, come back here and install the N8R8 version instead. A successful flash only means the firmware was written to the board; it does not guarantee that you selected the correct S3 version.

The boards can look nearly identical. The module marking, not the board color or USB connector, determines which S3 firmware you need.

ESP32-S3 wireless updates

Already running PMT on an S3? You may not need the USB cable.

Supported ESP32-S3 N16R8 and N8R8 throttle devices can install the catalog's latest firmware from the Poor Man's Throttle app when Wi-Fi is connected. OTA always targets the catalog latest; by default CV15=0 refuses an older catalog version, while CV15=1 explicitly permits that catalog downgrade. Before you install

Back up your configuration first.

Use the Poor Man's Throttle app to create a configuration backup before every firmware installation. Normal updates are designed to keep your settings, but a backup gives you a safe recovery copy if something unexpected happens.

Step 2

Get your computer ready.

Windows Use Google Chrome or Microsoft Edge.
Mac Use Google Chrome. Do not use Safari for firmware flashing.
  • Use a USB data cable. Some USB cables only charge and cannot install firmware.
  • Plug the ESP32 directly into the computer when possible.
  • Close Arduino Serial Monitor or any other program that may be using the ESP32 USB/serial connection.
Step 3

Keep your settings unless you intentionally want to start over.

Keep my settings — Recommended

When ESP Web Tools asks about erasing the device, leave Erase device off/unchecked. The firmware will be updated without intentionally wiping your saved configuration.

Erase everything / Start fresh

Only choose erase if you intentionally want to delete the saved configuration and start from a clean device. You will need to restore a backup or configure the throttle again.

What happens next

Follow the installer one step at a time.

  1. Click the firmware install button above.
  2. Choose the USB/serial device that represents your ESP32 and connect to it.
  3. Confirm the installation.
  4. For a normal update, keep Erase device off/unchecked.
  5. Wait until ESP Web Tools says the installation has finished. Do not unplug the board while it is writing.
  6. Optional exact-build check: after reconnecting, send VV from the PMT terminal. The response identifies the installed firmware build.
Troubleshooting If the installer cannot start flashing
  • Confirm you are using a USB data cable, not a charge-only cable.
  • Close Arduino Serial Monitor and other programs that might already be using the ESP32 connection.
  • If the device connects but flashing does not begin, hold BOOT, start the install and select the device. Release BOOT when erasing/writing begins.
  • On Windows, the Classic ESP32-WROOM-32 commonly uses a CP210x USB-to-serial interface. If Windows does not create a usable port, you can open the Silicon Labs CP210x driver page.
