Firmware Installation
Recommended

Install the latest firmware.

What’s new in the firmware → latest changes and features

Use Chrome or Edge for flashing. Use a data-capable USB cable.

If the device connects but doesn’t begin flashing, hold BOOT, click Install, select the port, then release BOOT once “Erasing/Writing” begins.

Optional

Install an earlier firmware version.

Useful if you want to roll back after testing a newer release.

Troubleshooting

If installation does not go as expected.

  • Close Arduino Serial Monitor or anything else using the COM port.
  • Windows: CP2102 usually works automatically. If not, install the Silicon Labs CP210x driver. Open CP210x driver
  • If you see repeated resets, run the latest install again.
