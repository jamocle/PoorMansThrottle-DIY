This page is for a firmware build supplied directly to you for testing, diagnosis, or a bespoke change. It is separate from the normal Poor Man's Throttle firmware releases.

Experimental firmware

Only install the bespoke firmware you were asked to test.

This firmware may contain changes that are not part of a normal public release. Do not use this page on another throttle unless you were specifically asked to do so.

Step 1

Choose your exact ESP32 board.

Match the board in your hand to one of the choices below. For an ESP32-S3, read the writing on the metal ESP32 module and find N16R8 or N8R8. Do not guess.

Step 2

Confirm the board before continuing.

!
Before you install

Back up your configuration first.

Use the Poor Man's Throttle app to create a configuration backup before installing experimental firmware. Unless you were specifically told to start fresh, keep Erase device off/unchecked when ESP Web Tools asks.

Step 3

Get your computer ready.

Windows Use Google Chrome or Microsoft Edge.
Mac Use Google Chrome. Do not use Safari for firmware flashing.
  • Use a USB data cable, not a charge-only cable.
  • Plug the ESP32 directly into the computer when possible.
  • Close Arduino Serial Monitor or anything else using the ESP32 USB/serial connection.
  • Do not unplug the ESP32 while firmware is being erased or written.
Step 4

Install the bespoke experimental firmware.

Ready to install

The installer will use the experimental firmware prepared for the board you confirmed above.

Use Chrome or Edge on Windows, or Chrome on Mac. Firmware flashing requires this page to be opened securely using HTTPS.
What happens next
  1. Click Install Bespoke Firmware.
  2. Choose the USB/serial device that represents your ESP32 and connect to it.
  3. Confirm the installation.
  4. Unless you were specifically told otherwise, keep Erase device off/unchecked.
  5. Wait for ESP Web Tools to report that installation has finished before unplugging the board.
Troubleshooting If the installer cannot start flashing
  • Confirm the USB cable supports data.
  • Close Arduino Serial Monitor and any other program using the ESP32 connection.
  • If the device connects but flashing does not begin, hold BOOT, start the install, select the device, then release BOOT when erasing/writing begins.
  • If you are unsure which board you have, stop and check the board/module marking before trying again.
